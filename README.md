# Zirconium HCI

Zirconium HCI is a personal x86_64 Fedora bootc desktop image based on
[Zirconium](https://github.com/zirconium-dev/zirconium), using Niri and
DankMaterialShell. It is an immutable, image-based workstation focused on
development, containers, virtualization, and normal desktop use.

Integrated tooling includes:

- Distrobox and container tooling
- libvirt, QEMU, and virt-manager
- Tailscale
- Gaze and Gaze GUI
- Native printing and scanning, including Pantum printer/scanner support
